# Project Title

This is the description of the following project wich has been done. in this task we are tying to develop a simple news aggregator.
fetching real-time news data from "News API" and present the latest headlines in an organized manner.

## Description

In this project the main goal is about sending request to the API in order to bring up the needed headlines such as news. as expected, we have bunch of features which were highly needed whereas Designing the News class with attributes "title", "description", "sourceName", "author", "url" and "publishedAt" and the method "displayNews" to display all information of that news or even Errors!
